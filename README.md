### Basic Paint in C
 
#### Welcome! This project is a implementation of a basic "Paint" program in C.

The Raylib external library was extremely important in making this project possible.
> 
> The source code is available too and to compile it (at least in Windows), make sure that you're in the project's folder and you will need to run the following line in terminal:
> 
> <code>gcc -o paint paint.c  -I include -L lib -lraylib -lgdi32</code>
> 
> You can also add the <code>-Wextra -Wall</code> flags to help you to see what's wrong.
>
> After compiling, you can execute it running <code>./paint</code>
